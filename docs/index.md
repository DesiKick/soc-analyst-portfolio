# SOC Analyst Lab Portfolio & Documentation

Welcome to my cybersecurity lab notebook. This portfolio documents hands-on defensive security simulations, alert triage, threat-hunting scenarios, and log analysis performed across virtual and cloud environments.

---

## 🎯 Focus Areas
- **Security Operations & Alert Triage:** Analyzing endpoint and network telemetry to determine True/False positives.
- **Log Correlation & Detection:** Writing and tuning detection queries using SPL and KQL.
- **Threat Hunting & Forensics:** Investigating packet captures (PCAPs), process trees, and persistence artifacts.
- **Defensive Frameworks:** Mapping adversary tactics directly to the **MITRE ATT&CK** matrix.

- **Traffic Analysis:** Wireshark, Zeek
- **Triage & OSINT:** VirusTotal, AbuseIPDB, Any.Run
- **Core OS:** Windows Server, Ubuntu Linux
